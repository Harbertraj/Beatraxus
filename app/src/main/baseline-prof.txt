# --- UI layer ---------------------------------------------------------------------------------------------------------
# The profile above only covered start-up, so the first time Settings, Now Playing, Studio DSP, the library or the lyrics view
# opened, all of their code (hundreds of composables) ran interpreted / JIT-compiling WHILE the screen was sliding in, which is
# what showed as a stutter on the first open. These wildcard rules (supported by the baseline-profile compiler) have the
# installer pre-compile that code. HSP = hot, startup and post-startup. They are broad on purpose: a hand-written profile cannot
# know the exact methods, and a device-recorded one (a Macrobenchmark BaselineProfileRule run) should replace them when available.
